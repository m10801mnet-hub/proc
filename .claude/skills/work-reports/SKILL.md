# 業務報告書

## 定型（1件1ページ以内）
```
件名：YYYY/MM/DD（曜）○○ 報告（作成：的場）
1. 結論（1〜2行）
2. 実施内容（時系列：HH:MM 内容／担当／結果）
3. 数値（作業量・時間・人数・不具合件数）
4. 問題・リスク（発生事象／原因／暫定対応／恒久対策）
5. 次アクション（誰が・いつまでに・何を）
6. 共有・確認事項
```
## ルール
- 事実と判断を分ける。推測には「推定」と書く。
- 深夜対応・長時間勤務は**勤務間インターバル（11時間目安）**の確保状況を必ず記載し、不足なら翌日の調整案を併記。
- 複数スレッドの統合：日付→案件→発言者で並べ、重複を削除し、未解決事項を末尾に集約。
- 出力はテキスト（LINE/メール貼り付け用）と、必要に応じてPDF。

※ 過去セッション（八中の朝報告書、ルーティン報告書のスレッド統合、深夜対応インターバル）の具体的な宛先・書式が分かれば追記する。
